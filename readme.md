## t-api

Телеграм бот, позволяющий получать уведомления об операциях по указанному брокерскому счету в Т-Банке.

### Отправка уведомлений об операциях на брокерском счету

1. Регистрация
- Для начала регистрации необходимо отправить команду `/start`.
- Затем необходимо предоставить инвестиционный токен с доступом на чтение.
- Бот получит информацию об инвестиционных счетах и предложит выбрать счет для отслеживания операций.
- После выбора счета он сохранится как отслеживаемый для данного пользователя.
- После этого с определенной периодичностью бот присылает сообщением выполненные операции на данном счете по мере их выполнения.

2. Чтение операций
Бот с определенной периодичностью (1 раз в минуту) получает данные об операциях по сохраненному инвестиционному счету и 
отправляет их пользователю в формате:
- Название операции,
- Тикер,
- Количество инструментов,
- Стоимость инструментов,
- Цена за единицу инструмента,
- Дата операции.

Получает данные об операциях за время T, где T - периодичность отправки`.

3. Остановка отслеживания
Доступна команда "Приостановить следование", которая отключает чтение операций, пока не будет отправлена команда 
"Продолжить следование".
